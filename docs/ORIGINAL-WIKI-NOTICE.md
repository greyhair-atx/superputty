## Community edition

Current community code and documentation updates are maintained by **C. Thornton** at [greyhair-atx/superputty](https://github.com/greyhair-atx/superputty).

The community manual reorganizes the original material, removes obsolete instructions, and documents the current 64-bit runtime, installers, session handling, docking theme, security changes, SCP authentication, and troubleshooting workflow. Links to the upstream manual are retained for historical reference.
