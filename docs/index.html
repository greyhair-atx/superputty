Choose how to install

Requirements: Tested on Windows 11 x64. Expected to install and run on Windows 10 x64 with .NET Framework 4.8 or later, but Windows 10 has not been tested for this release. Install the external clients needed for your sessions. Windows 10’s vendor support depends on your edition and servicing arrangement. No x86 or native ARM64 package is provided. Remote protocols and authentication depend on your installed clients.

Current user

Installs into your Local AppData directory. Does not require administrator approval.

*-current-user-win-x64-signed.msi

All users

Installs into 64-bit Program Files. Requires administrator approval.

*-all-users-win-x64-signed.msi

No-install ZIP

Extract and run SuperPutty.exe. Existing profile preferences take precedence; this is not an isolated portable profile.

*-portable-win-x64.zip

Back up settings before upgrading. Existing filenames and settings paths are preserved. Upstream coexistence is unsupported. Installation guide · Upgrade and compatibility guide

Verify before you run

Check the MSI signature before installation, or the extracted executable before launching. Signed releases must show Valid, signer Christopher Thornton, and a timestamp certificate.

Get-AuthenticodeSignature .\SuperPuTTY-CE-1.8.2-current-user-win-x64-signed.msi | Format-List
Get-AuthenticodeSignature .\SuperPutty.exe | Format-List
Get-FileHash .\SuperPuTTY-CE-1.8.2-current-user-win-x64-signed.msi -Algorithm SHA256

Compare the complete SHA-256 value with the matching line in SuperPuTTY-CE-1.8.2-SHA256SUMS.txt from the same release. These filenames identify the stable 1.8.2 release. Checksums detect changed bytes; verify Authenticode as well. A valid signature is not a guarantee that software has no vulnerabilities.
