# SuperPuTTY Community Edition 1.8.3-rc.1

Release candidate for Windows x64 and .NET Framework 4.8. This prerelease includes all application changes since 1.8.2; 1.8.2 remains the stable release.

## Dark mode

**Thank you to [@dustinreeves](https://github.com/dustinreeves) for contributing dark mode in [PR #2](https://github.com/greyhair-atx/superputty/pull/2)!** The original contribution adds Light, Dark and System themes, dark docking panes and menus, dialog/control colors, dark title bars, and improved icon transparency.

This candidate also adds **Dark Modern**, inspired by VS Code's Dark Modern palette, with charcoal surfaces, flat document tabs, blue active-tab indicators, coordinated menus and inputs, and readable Quick Selector text. It fixes restart prompts between dark styles and native-control theme handling after window-handle recreation.

Select **Options > GUI > Misc > Theme**, save, then restart. Light remains the default. System resolves the Windows app preference at startup and uses the original Dark style when Windows is dark. Native message boxes and external PuTTY terminals/RDP/VNC content retain their own colors.

## Sessions and terminal hosting

- Add **Ping** to the saved-session context menu to open a temporary local ping tab without creating a saved session.
- Improve local terminal process identification/window capture and terminal titles.
- Preserve the 1.8.2 PuTTY multi-session activation fix.

## SCP reliability

- Improve directory navigation, refresh, busy-state handling, and browser/transfer cleanup when tabs close.
- Allow refresh to retry a failed initial directory listing and recover normally.
- Preserve final PSCP output lines across reader modes, avoid duplicate prompt notifications, and improve transfer-progress parsing, including locale-sensitive values.
- Add regression tests for ping sessions, process lifecycle, and SCP recovery/output handling.

## Packages and testing

Use the signed current-user MSI, signed all-users MSI, or portable ZIP. Release assets include SHA-256 checksums, a runtime-file SBOM, build provenance, and validation results. PuTTY/PSCP and external viewers are separate prerequisites. The ZIP uses normal existing settings and does not isolate your profile; back up settings before testing.

The application displays **1.8.3-rc.1**. Windows Installer and numeric file/assembly metadata use **1.8.3** / **1.8.3.0**, because MSI does not support SemVer prerelease labels. Uninstall this RC before installing another package with the same MSI version, including a future 1.8.3 final, to avoid same-version installer ambiguity. Settings should be backed up and preserved during that transition.

Validation covers Release/x64 builds, non-network unit tests, theme/dialog and docking checks, application shutdown, and selected local/loopback terminal checks; see the attached validation report for exact results. Full authenticated SSH/PSCP/RDP/VNC coverage, a complete installer upgrade matrix, and high-DPI visual coverage are not claimed. This candidate is not a stable release.

This is an independently maintained community fork, not an official upstream SuperPuTTY or PuTTY release.
