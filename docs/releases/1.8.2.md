# SuperPuTTY Community Edition 1.8.2

Maintenance release for Windows x64 with .NET Framework 4.8. Replaces withdrawn version 1.8.1, which had an SSH session regression. Version 1.8.1 remains withdrawn.

## SSH regression fix

Opening multiple PuTTY sessions could leave a selected terminal inactive, with an outlined cursor, missing keyboard interaction, or incorrect window display. The embedding change in 1.8.1 converted PuTTY into a child-style window, disrupting the activation behavior used by the existing host.

This release preserves PuTTY's established window style and activation behavior. Capture verification remains in place and checks the actual native parent with GetAncestor(GA_PARENT). The unsuccessful SetFocus-only test change is not included.

The maintainer confirmed that the second test candidate works with three copies of Test_SSH. A new live regression test opens three duplicate sessions in the real docking interface and checks activation, keyboard focus, exact window bounds, and typed input reaching only the selected session. Its automated connections use raw loopback peers rather than remote SSH authentication.

## Other changes since 1.8.0

- Improve script cancellation, prompt handling, key parsing/repeat counts and input ordering; serialize scripts sharing a session.
- Wait for embedded RDP login before starting scripts; improve asynchronous client startup and bounded HTTPS script downloads.
- Preserve default layouts during renames and validate layout filenames.
- Harden external-client argument quoting and URL construction; improve backup retention and use 24-hour timestamps.
- Move Cygterm, Mintty, Raw, Rlogin and Telnet to the bottom of protocol selectors.

Invalid SENDKEY expressions and unsupported modified special keys stop the script with a line-numbered error. Use SENDCHAR for literal strings. See the [scripting manual](https://github.com/greyhair-atx/superputty/blob/sp-1.8.2/docs/manual/scripting.md).

## Packages and verification

Choose the signed current-user MSI, signed all-users MSI, or no-install ZIP. PuTTY/PSCP and desktop viewers are separate prerequisites. Existing settings and session paths are preserved; the ZIP uses existing profile settings and is not an isolated profile.

Release assets include SHA-256 checksums, a runtime-file SBOM, a build manifest, VirusTotal Markdown/JSON reports for the executable, five shipped DLLs and both signed installers, and a validation report. Consult the attached reports for final results. Zero detections is not a guarantee of safety.

## Validation scope

The release is checked with a Release/x64 build, 220 nonnetwork unit tests, live three-session PuTTY interaction, terminal scripting, shutdown and console capture checks. RDP login readiness tests use simulated login events. No new live remote RDP/VNC authentication or installer-upgrade matrix is claimed for these final packages. Installer metadata, extracted payloads, signatures and ZIP/SBOM hashes are verified separately.

Windows 11 x64 is the local validation environment; Windows 10 compatibility is expected but untested. This is an independently maintained community fork, not an official upstream SuperPuTTY or PuTTY release.
