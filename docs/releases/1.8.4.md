## New installer, new look

The redesigned installer uses a modern wizard and supports **both installation scopes in one signed download**: choose **current user** to install just for your account without administrator rights, or **all users / machine** to install for everyone with administrator approval. Download `SuperPuTTY-CE-1.8.4-setup-win-x64.exe`; separate per-scope MSI downloads are no longer needed. Existing MSI installations require the [explicit uninstall/install migration](../manual/upgrading.md).

## Changes since 1.8.3

- Fix tab-strip overflow hover and close targeting when many sessions are open. Regression coverage exercises 20 and 30 tabs in Light and Dark Modern themes.
- Keep tab capacity unrestricted by application policy; the Connect All setting is a confirmation threshold. Add coverage above 255 tabs and release overflow-list menu items and icon bitmaps when rebuilding or closing the list.
- Add an opt-in GUI setting for middle-clicking session tabs closed without confirmation. X-button confirmation remains enabled for active/unknown sessions, with the shorter `Close tab '<tab name>'?` prompt.
- Reduce the embedded PuTTY frame to a consistent 2px gray border. Preserve terminal activation, keyboard focus and scrollbars, including after PuTTY changes its window settings. PuTTY's text padding remains controlled by its saved session.
- Improve connection-aware close confirmation for PuTTY and RDP. Unknown connection state remains conservative; disconnecting RDP is distinct from logging off its remote session.
- Add opt-in interactive PSCP authentication for password/MFA prompts, with cancellation and timeout handling. The maintainer accepted real-server password/token challenge responses and SSH connection sharing, closing the MFA gate.
- Fix null username handling and add regression coverage.
- Replace the release packaging path with one signed Inno EXE supporting current-user and machine scope. Include a signed-application portable ZIP, checksums, exact runtime SBOM and build manifest.
- Preserve prior Inno payloads and durable recovery data during upgrades. Reject unsafe recovery, same-version installs and downgrades. Compile failure-injection hooks only into explicit test fixtures.
- Clarify installation scope, MSI migration, interrupted recovery and settings backup instructions.

## Additional review fixes

- Validate the trimmed session name before the editor accepts it, while preserving exact stored-name checks in Session Details. Apply tree-editor edits transactionally so conflicts and failed writes preserve the original session.
- Preserve empty folders, expansion and selection during both tree-editor and File > Save Current Session saves, including failed writes. Keep replacement, deletion and move refreshes distinct so removed folders are not restored.
- Fix Help > Diagnostics > Log Window Locations when SCP or other managed documents are open. Log each live document's bounds without assuming a PuTTY host, skip disposed/uncreated controls and mark missing or stale application-window bounds unavailable.
- Recognize PSCP's `Configured password was not accepted` fatal message as an authentication failure even if the preceding `Access denied` text is split. Request credentials again for listings and provide a useful authentication/additional-prompts message for failed transfers.
- Validate current-session saves against both session and folder paths before changing the live catalog. Preserve session identity and roll back edited fields, catalog membership and the index if saving fails.
- Flush pending folder moves when the session tree closes or is disposed. Report failed delayed saves, retain pending changes and block normal closure if a flush fails.
- Include SCP documents safely in the Switch Session selector and skip disposed or unsupported documents.
- Clear or rebind Session Details when tree selection disappears or a selected session is replaced. Detach its session, tree and helper subscriptions on closure or disposal.
- Reject replacement catalogs whose session names do not match the last component of their IDs, allowing differences in case.
- Apply docking restrictions repeatedly without toggling floating back on; restore each document's original permissions when restrictions are disabled.
- Build session menus from path positions so repeated names such as `Prod/Prod` retain their hierarchy. Build on the UI thread and dispose replaced menu items.

- Validate the entire replacement session catalog before applying a reload. Malformed records, duplicate IDs and session/folder path conflicts preserve the existing catalog and tree.
- Move, rename and delete folders using the complete session catalog, including sessions hidden by search. Reject hidden destination conflicts and retain expanded folders during moves and renames.
- Subscribe each tree to a session's events once and detach handlers on rebuild, removal, close and disposal.
- Use case-insensitive session IDs consistently with the tree. Reject conflicting paths, keep imported names unique and validate edits against sessions hidden by search.

- Report standalone external-client launch failures, parse IPv6 connection URLs with custom ports correctly, and preserve quotation marks/backslashes in session IDs passed to a new instance.
- Treat percent signs and brackets as literal Quick Selector search text. Keep separate snapshots for rapid session saves and prune only recognized timestamped backups, preserving unrelated XML files.

- Import portable PuTTY protocol names without case sensitivity and skip locked or unreadable session files while continuing valid entries. Report folder-level import failures.
- Preserve remote SCP file sizes above 2 GiB and parse English listing timestamps independently of Windows language settings.

- Update Apache log4net from 3.4.0 to 3.5.0 in the application and tests.

- Update session IDs at every nested folder depth when moving a session folder, preserving the new paths after saving and reloading.
- Escape apostrophes in Quick Selector searches and handle arrow navigation with no results or a hidden name column.

- Make stale SCP Cancel actions harmless when a transfer has already finished, and reject drops without a loaded destination.
- Reject missing or inaccessible dropped files without leaving stale drag state. Use 64-bit arithmetic for large-transfer size estimates.
- Keep layouts listed when deletion fails and show an actionable error. Report settings save failures so default-layout renames roll back; restore the previous default when saving a new default fails.
- Validate PuTTYCM exports and report malformed XML, missing fields, invalid ports and unsupported protocols. Skip invalid or inaccessible PuTTY registry sessions while importing the remaining valid entries.
- Handle unavailable single-instance IPC endpoints with a warning. Forward `-layout` commands to the existing instance and resolve layouts and sessions on its UI thread.
- Search sessions without hostnames safely, including sessions that use saved PuTTY profiles. Bound regex matching to 100 ms and disable an expression after it times out so later sessions do not repeat the delay.
- Preserve custom ports when importing RDP history, validate endpoints and format IPv6 addresses correctly for external RDP clients.
- Report WinSCP/FileZilla validation and process-launch failures with guidance to check the session hostname and configured executable.

## Migration and limits

1.8.3 MSI users must explicitly uninstall their actual installed ProductCode, then install Inno in the original scope. Keep private settings backups and the verified previous MSI first. **These operations are not atomic.** Automatic MSI-to-Inno upgrade is not supported. See [installation](../manual/installation.md) and [upgrading](../manual/upgrading.md).

Normal Inno-to-Inno upgrades use a strictly newer version in the same scope. On interruption, close setup and rerun the same installer/scope; preserve logs and recovery files. Do not delete the recovery journal to force continuation.

Windows x64, Windows 10 build 19041 or later, .NET Framework 4.8 and separately installed connection clients are required. Windows 11 signed Inno upgrade/recovery, live RDP reconnect and published 1.8.3 MSI-to-Inno migration passed in both scopes for the final `36dc25e` release bytes; see the [November 8 validation record](1.8.4-VALIDATION-20261108.md). The diagnostics, authentication-error and session-save follow-ups are included. Real PSCP MFA and connection sharing have maintainer acceptance. Acceptance testing targets Windows 11 x64; Windows 10 compatibility remains unvalidated. The ZIP shares preference discovery with installed copies and does not isolate a profile.

The WinGet package submission remains withdrawn. Review manifests describe Inno honestly and are not submitted or published by this build. The separate WinGet client correction remains independent.

See the [executed test plan](1.8.4-TEST-PLAN.md) and [publication results](../RELEASE-1.8.4-RESULTS.md). Release `sp-1.8.4` is published on both hosts; a WinGet catalog update remains separate.
