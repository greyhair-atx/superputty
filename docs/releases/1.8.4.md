# SuperPuTTY Community Edition 1.8.4

**Unpublished candidate — testing and review are required before release.** Application version: 1.8.4.0. The latest published stable version remains 1.8.3.

## Changes since 1.8.3

- Fix tab-strip overflow hover and close targeting when many sessions are open. Regression coverage exercises 20 and 30 tabs in Light and Dark Modern themes.
- Keep tab capacity unrestricted by application policy; the Connect All setting is a confirmation threshold. Add coverage above 255 tabs and release overflow-list menu items and icon bitmaps when rebuilding or closing the list.
- Improve connection-aware close confirmation for PuTTY and RDP. Unknown connection state remains conservative; disconnecting RDP is distinct from logging off its remote session.
- Add opt-in interactive PSCP authentication for password/MFA prompts, with cancellation and timeout handling. Real-server MFA validation remains a release gate.
- Fix null username handling and add regression coverage.
- Replace the release packaging path with one signed Inno EXE supporting current-user and machine scope. Include a signed-application portable ZIP, checksums, exact runtime SBOM and build manifest.
- Preserve prior Inno payloads and durable recovery data during upgrades. Reject unsafe recovery, same-version installs and downgrades. Compile failure-injection hooks only into explicit test fixtures.
- Clarify installation scope, MSI migration, interrupted recovery and settings backup instructions.

## Migration and limits

1.8.3 MSI users must explicitly uninstall their actual installed ProductCode, then install Inno in the original scope. Keep private settings backups and the verified previous MSI first. **These operations are not atomic.** Automatic MSI-to-Inno upgrade is not supported. See [installation](../manual/installation.md) and [upgrading](../manual/upgrading.md).

Normal Inno-to-Inno upgrades use a strictly newer version in the same scope. On interruption, close setup and rerun the same installer/scope; preserve logs and recovery files. Do not delete the recovery journal to force continuation.

Windows x64, Windows 10 build 19041 or later, .NET Framework 4.8 and separately installed connection clients are required. Windows 10, real RDP reconnect and real PSCP MFA tests remain pending. The ZIP shares preference discovery with installed copies and does not isolate a profile.

The WinGet package submission remains withdrawn. Review manifests describe Inno honestly and are not submitted or published by this build. The separate WinGet client correction remains independent.

See the [candidate test plan](1.8.4-TEST-PLAN.md) for release gates. No release tag or public release has been created.
