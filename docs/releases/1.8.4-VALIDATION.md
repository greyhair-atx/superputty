Recovery used seven signed fixtures containing the current application payload, with explicit test-only package versions 1.8.4.100/101 and failure hooks. Both scopes passed payload/registry write rollback, same-version rejection, locked-file rejection, failed shortcut activation recovery, corrupt-backup rejection, interrupted file/activation recovery, successful upgrade and downgrade rejection. The production installer contains no failure hooks.

The live RDP test used the signed application's RDP ActiveX panel against a Windows 11 Enterprise Evaluation VM. Windows session events 21/24/25 confirmed login, disconnect and reconnect to the same server session (ID 9), without a logoff. It exercised the live control's `Reconnect` API; network-loss-induced reconnection was not tested.

## Test-run qualifications and cleanup

- The initial non-admin recovery attempt under WinRM encountered a WMI access restriction in the harness while stopping an interrupted installer. The retained journal was recovered, and the complete non-admin recovery matrix passed under a local scheduled-task token.
- The signed regression run hit a PID-file read/write race in `ProcessLifecycleRegressionTests.ClosingScpPresentersStopsTheirChildProcess(False)`. Both cases of that lifecycle test passed on targeted retry. This was not a clean 397/397 signed-suite run; the earlier unsigned build had passed 397/397.
- All test installations and recovery journals were removed, and original settings hashes were preserved. Temporary tasks, the batch-logon right, the test account and the stage write grant were removed. Windows still reported the temporary profile loaded, so its directory was retained instead of forcibly unloaded. The test-created RDP session was logged off only after verifying client-close behavior.

Raw evidence is retained locally under `artifacts/release-validation-bd06313-20261107/`: `validation-summary.json`, `vm-final-results/`, `vm-logs/`, `rdp-live/`, `signed-regression-results/` and `cleanup-summary.json`. Private environment details, credentials and raw settings backups are not included in this document.
