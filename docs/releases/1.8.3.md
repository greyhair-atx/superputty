# SuperPuTTY Community Edition 1.8.3

Stable release for Windows x64 and .NET Framework 4.8.

## Themes

Thank you to [@dustinreeves](https://github.com/dustinreeves) for contributing dark mode in [PR #2](https://github.com/greyhair-atx/superputty/pull/2), including Light, Dark and System themes, dark docking panes and menus, dialog colors, dark title bars and icon transparency.

Dark Modern adds a VS Code inspired palette, flat document tabs and blue active-tab indicators. Its toolbars match the near-black menu background, with matching charcoal outlines around Protocol, Session, Commands, Host and Login inputs.

Choose **Tools > Options > GUI > Misc > Theme**, save and restart. Light remains the default. System follows the Windows app preference at startup. External terminals and remote desktop content keep their own colors.

## Session tools

- **Tools > Options > Protocols** controls which protocols appear in the connection toolbar and new-session dropdowns. All are shown by default; keep at least one checked. Changes apply on save without restarting. Existing sessions remain usable, and their current protocol remains available when editing.
- **Copy IP/Hostname** on a saved session's right-click menu copies its Host field exactly as saved. The action is disabled for an empty host.
- **Ping**, **Ping continuously** and **Ping externally** provide quick host checks; tabbed ping sessions are temporary.
- Improve terminal process capture and titles while preserving the 1.8.2 PuTTY multi-session activation fix.
- Improve SCP navigation, refresh/retry, busy state, transfer-progress parsing and cleanup. Preserve final PSCP output and avoid duplicate prompt notifications.

## Packages and compatibility

Use the signed current-user MSI, signed all-users MSI or portable ZIP. Release assets include SHA-256 checksums, a runtime-file SBOM, build provenance and validation results. PuTTY/PSCP and external viewers are separate prerequisites. The ZIP uses existing settings discovery; it does not isolate your profile.

Back up settings before upgrading. If you installed **1.8.3-rc.1**, uninstall it before installing 1.8.3: both use the numeric MSI version 1.8.3, so a same-version upgrade is ambiguous. Existing 1.8.2 packages remain available; 1.8.1 remains withdrawn.

Validation results accompany the release. Windows 11 x64 is the local test platform. Windows 10, a complete installation/upgrade matrix, high-DPI visual coverage and new authenticated SSH/PSCP/RDP/VNC end-to-end tests are not claimed.

This is an independently maintained community fork, not an official upstream SuperPuTTY or PuTTY release.
