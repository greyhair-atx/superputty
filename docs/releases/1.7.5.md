# SuperPuTTY 1.7.5

SuperPuTTY 1.7.5 is the Windows x64 community release built from commit `96a5e04043967046c78ada8bc55765d24881072c`, tagged `sp-1.7.5`. The application reports version **1.7.5.0** and requires .NET Framework 4.8.

Download it from [GitHub](https://github.com/greyhair-atx/superputty/releases/tag/sp-1.7.5) or [Gitea](https://gitea.uberx.org/vscode/superputty/releases/tag/sp-1.7.5).

## What's new

- TigerVNC uses compatible startup arguments and is recognized even when its executable is renamed or has a versioned filename. The desktop window replaces the captured login dialog inside the tab, including after reconnecting. Viewer exits during startup are handled without the process-information exception.
- Closing an active tab asks for confirmation, with **Cancel** selected by default.
- **RestartSession** can be assigned under **Tools > Options > Shortcuts** for supported PuTTY sessions. It has no default key binding.
- Console refocus defaults are three attempts at 40 ms intervals.
- Documentation includes screenshots of session setup, layouts, shortcuts, close confirmation, and file transfers, plus supplied RDP and VNC desktop examples.

See the [user manual](../manual/README.md) for usage and [ReleaseNotes.txt](../../ReleaseNotes.txt) for version history.

## Validation

Release validation passed all 127 isolated tests, both installer payload and architecture checks, version and signature checks, application shutdown tests, and real Command Prompt/PowerShell window capture tests. The isolated VNC tests use local test windows; these results do not establish successful live VNC authentication against every server/viewer combination.

All six EXE/DLL payload hashes extracted from both installers matched the VirusTotal submissions. After publication, all five release downloads on each host were downloaded and verified against local SHA-256 hashes.
