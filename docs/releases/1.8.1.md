# SuperPuTTY Community Edition 1.8.1

Maintenance release following 1.8.0, for Windows x64 with .NET Framework 4.8.

## Fixes

- Stop scripts and pending prompts when their target sessions close. Canceling an input prompt sends no text or Enter.
- Keep scripted keys and text in order. Correct terminal character shortcuts such as Ctrl+C, Shift+C, and Alt+x; honor named-key repeat counts.
- Run scripts sharing a target session one at a time, including sleeps and prompts. Scripts on separate sessions can run concurrently.
- Allow OPENSESSION with an initially empty selection. Embedded Microsoft RDP startup scripts wait for login completion.
- Load remote startup scripts asynchronously with a bounded HTTPS download; improve application startup, window capture, and RDP authentication handling.
- Preserve the default-layout setting on rename; validate layout filenames and handle rename failures.
- Improve backup retention and use 24-hour timestamps. Move Cygterm, Mintty, Raw, Rlogin, and Telnet to the bottom of the protocol menus.
- Harden external-client argument quoting and URL construction, including paths and credentials.

## Scripting compatibility

Invalid SENDKEY expressions now stop the script with a line-numbered error. Use SENDCHAR for literal strings; SENDKEY accepts a single letter/digit or a named key with an optional repeat count (1–10000).

Character shortcuts send terminal characters: Ctrl+C sends ETX, Shift+C sends uppercase C, and Alt+x sends Escape followed by x. Modified special keys such as Ctrl+Left, Shift+F1, and Alt+Tab are explicitly unsupported for background terminal input. Shifted digits use the US symbol mapping.

Script targets are fixed when Run is clicked. Newly opened sessions are not automatically added. Command-toolbar input to a session reserved by a script is rejected with a busy message. See the [scripting manual](https://github.com/greyhair-atx/superputty/blob/sp-1.8.1/docs/manual/scripting.md).

## Packages and verification

Choose the current-user MSI, the all-users MSI, or the no-install ZIP. The application and installers are signed by Christopher Thornton and timestamped. PuTTY/PSCP and desktop viewers are separate prerequisites.

The release includes SHA-256 checksums, an exact runtime-file SBOM, a build manifest, and VirusTotal Markdown/JSON reports for the final executable, all five shipped DLLs, and both signed installers. Consult those reports for actual engine results and scan limitations; a clean scan is not a guarantee of safety.

## Validation scope

The release is checked with a Release/x64 solution rebuild, 219 nonnetwork tests, PuTTY loopback input, shutdown, and console-window capture checks. RDP login readiness is exercised with simulated login events; no live remote RDP/VNC/SSH authentication is claimed by those tests. Package signatures, installer metadata, extracted payloads, and ZIP/SBOM hashes are verified separately.

Windows 11 x64 is the validation environment. Windows 10 compatibility is expected but untested. See the accompanying release validation report for final installer-upgrade coverage and any limitations.

Existing published releases remain unchanged. This is an independently maintained community fork, not an official upstream SuperPuTTY or PuTTY release.
