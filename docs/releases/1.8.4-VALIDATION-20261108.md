## Visual review and accepted manual scope

Codex reviewed nine rendered captures from the exact signed application: Options, About and a 30-document docking/tab fixture in Light, Dark and Dark Modern. The middle-click option was visible, unclipped and off by default; labels were readable, long tab names were truncated within their tabs, active/overflow affordances were visible, and About showed 1.8.4.0 with lineage and license attribution. No blocking rendering issue was observed.

These are 96-DPI WinForms form/pane renders, not 30 live connections or a new physical display-scaling test. The separate 40 interactive tests cover tab behavior, confirmation/cancellation, persistence, resizing and overflow. The maintainer's earlier 100%/125%/150%/200% scaling/session-continuity acceptance, RDP network-loss recovery acceptance, and real-server password/token MFA plus SSH-sharing acceptance remain accepted. They were not claimed as new manual tests of this build. Windows 10 acceptance remains excluded and its compatibility remains unvalidated.

## Harness qualifications and cleanup

The signed regression suites and installer matrices passed on their first runs. The supplementary capture helper required corrections: its standalone dock panel initially lacked the application's default theme; fresh-account Windows first-logon/Start-menu overlays obscured desktop captures; and whole-form rendering omitted native docking panes. Final review used explicit form/pane rendering, with all 30 documents and their pane geometry checked. Initial captures and failed desktop-capture attempts are retained separately. None of these corrections rebuilt or re-signed the application or installer.

An initial cleanup comparison incorrectly wrapped a Windows PowerShell 5.1 JSON array and was corrected before cleanup. A subsequent file-by-file comparison verified all 65 original files unchanged. No original file required restoration.

The VM's existing older current-user 1.8.4 installation was backed up and left untouched. Both temporary desktop sessions were logged off after verifying that client close alone left them disconnected. Six temporary tasks, both test accounts and their profiles, and the temporary stage write grant were removed. No test application process remained. Temporary encrypted credential files were cleared to zero bytes. Private backups, credentials and fixtures are not part of the release bundle.

Local evidence is retained under `artifacts/release-validation-36dc25e-20261108-103735/`: `signed-candidate/`, `local-results/`, `vm-results/`, `vm-logs/`, `visual-pane-reviewed/`, both tooling-result directories, `server-rdp-events.json`, `visual-review-summary.json` and `cleanup-summary.json`. The preceding executable-only test report remains separate and does not identify the final installer bytes.

## Release decision

The maintainer authorized publication after clean VirusTotal results. Release `sp-1.8.4` is published on GitHub and Gitea, marked latest on both, and all 22 public downloads match the local inventory. The ten analyses cover the signed executable, five runtime DLLs, signed installer, signed uninstaller, portable ZIP and frozen source archive. The application, setup and ZIP retain the hashes above; publication updates affect only guide/approval/report metadata and its checksums. No WinGet submission was created. Any application or installer-source change requires a new candidate and appropriate validation.
